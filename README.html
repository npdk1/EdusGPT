🔐 Kho Mã Hóa Latin - Trung Quốc (Chinese-Latin Cipher V1)

EdusGPT bảo vệ toàn bộ kho bài học và bộ nhớ đệm âm thanh trong thư mục data/ bằng hệ thống mã hóa độc quyền EDUS_ZH_LATIN_CIPHER_V1:

  • Mã hóa chuẩn công nghiệp: Sử dụng thuật toán AES-256-GCM với khóa bảo mật 256-bit dẫn xuất qua PBKDF2 từ machine identifier và secret key.
  • Xen kẽ CJK Glyph Transposition: Dữ liệu nhị phân sau khi mã hóa được chuyển đổi qua bộ codec hoán vị chữ cái Latin và các chữ Hán CJK tượng hình (tỉ lệ 1 ký tự Latin xen 3 chữ Hán), tạo thành văn bản mã hóa huyền bí, không thể đọc được bằng các công cụ bên ngoài.
  • Tính tương thích ngược: Tự động phát hiện và giải mã liền mạch các bài giảng JSON thuần trước đây mà không làm mất mát dữ liệu.

Khởi chạy nhanh

Windows: Nhấp đúp vào run.bat.

macOS hoặc Linux: ./run.sh

Cả hai script tự động kiểm tra Node 22+, cài dependencies thiếu, tự động sao chép .env.example thành .env nếu chưa có, giải phóng cổng 3000 và khởi động trình duyệt.

⚙️ Cấu hình Môi trường (.env.example ➔ .env)

Nếu bạn muốn cấu hình thủ công tệp biến môi trường:

# Trên Windows (CMD hoặc PowerShell):
copy .env.example .env

# Trên macOS / Linux:
cp .env.example .env

Mở tệp .env bằng trình soạn thảo bất kỳ và điền API key nhà cung cấp AI bạn muốn sử dụng (hoặc truy cập http://localhost:3000/setup trên trình duyệt để dán key trực tiếp):

AI_PROVIDER=groq
GROQ_API_KEY=gsk_your_groq_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
TOKENHARBOR_API_KEY=thk_live_your_key_here

Chạy thủ công:

npm install
npm run dev          # http://localhost:3000

Kiểm tra trạng thái runtime khi server đang mở:

powershell -ExecutionPolicy Bypass -File scripts/smoke-test.ps1

Cài đặt API key & AI Cục bộ

Mở /setup. Hệ thống hỗ trợ hai nhóm provider:

  • Cloud API: Gọi API qua mạng với Groq (Llama 3.3 70B), NVIDIA NIM (DeepSeek-R1, Llama 3) và Token Harbor. Server lưu key an toàn vào .env và giao diện luôn che mờ key.
  • Local Agent: Antigravity CLI (agy) kết nối trực tiếp với tài liệu học tập trong máy, tự động học và sinh bài giảng mà không tốn chi phí gọi API.

AI Studio & Tạo bài học

Mở /studio và nhập chủ đề, môn học, khối lớp, số cảnh, thời lượng và ghi chú. Bạn có thể đính kèm tài liệu tham khảo (pdf, docx, xlsx, txt, md, csv, json, tối đa 40 MB mỗi tệp).

Hỗ trợ 3 preset thời lượng: Thấp (3–5 slides, 1–2 phút), Trung bình (10–16 slides, 6–10 phút) và Cao (60–95 slides, 45–60 phút kèm ngân hàng 25+ câu hỏi trắc nghiệm ôn thi).

⚙️ Quản lý Thư viện & Tối ưu Dung lượng (Trim)

Mở /library. Mỗi thẻ bài giảng tích hợp icon cài đặt SVG hình Bánh răng mở ra bảng điều khiển thông minh:

  • Tối ưu dung lượng (Gọt bài): Xóa bỏ các slide bài thuyết minh và tệp âm thanh nặng, tiết kiệm đến 90% ổ cứng nhưng vẫn giữ trọn vẹn 100% Quiz và Flashcard để ôn thi.
  • Xóa an toàn vào Thùng rác: Tùy chọn di chuyển bài học vào thư mục data/temp_delete/ để khôi phục khi cần, hoặc xóa vĩnh viễn khỏi máy.
