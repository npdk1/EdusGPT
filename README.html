EdusGPT

Bạn đã chán ngấy việc đọc những khối văn bản dài dặc dặc từ chatbot AI? EdusGPT là giải pháp cục bộ (local-first) chuyển hóa mọi chủ đề hoặc tài liệu thành bài giảng tương tác có thuyết minh — hoàn chỉnh với slide động, phụ đề karaoke theo từng từ, công thức toán KaTeX chuẩn mực, trắc nghiệm tương tác ngắt nhịp và xuất file HTML độc lập để học tập ngoại tuyến. Mọi thứ hoạt động trực tiếp trên máy tính qua localhost:3000 — hoàn toàn không cần Docker hay cơ sở dữ liệu.

Tính năng nổi bật

  • 🎙️ Thuyết minh & Phụ đề Karaoke chuẩn xác: Tích hợp Microsoft Edge Neural TTS, Piper offline và VieNeu; phụ đề sáng từng từ theo thời gian thực với nhịp đọc sư phạm chuẩn mực.
  • 📐 Công thức Toán KaTeX: Hỗ trợ cú pháp $ ... $ (nội dòng) và $$ ... $$ (khối) trên slide, câu hỏi trắc nghiệm, các phương án lựa chọn và hội thoại trợ giảng.
  • 🧩 Trắc nghiệm tương tác ngắt nhịp (Quiz Gates): Tự động dừng bài giảng khi tới câu hỏi, chấm điểm trực tiếp và giải thích đáp án trước khi tiếp tục.
  • 🎴 Thẻ nhớ chủ động 3D (Active Recall Flashcards): Không gian ôn tập đa giác quan kèm giọng đọc, phóng to công thức và điều hướng phím tắt.
  • 🌐 Xuất file HTML độc lập (Standalone Player): Gói toàn bộ bài học, âm thanh base64 và engine phát GSAP vào 1 file .html duy nhất — mở xem ngay trên trình duyệt mà không cần web server hay database.
  • 🔍 Tìm kiếm & Chuyển bài trực tiếp trong Thư viện: Menu tìm kiếm bài học từ data/courses/ ngay trên thanh công cụ với huy hiệu trực quan (Thư viện, Đang phát).

Chạy nhanh

Windows: Nhấp đúp vào run.bat.

macOS hoặc Linux: ./run.sh

Các script khởi động tự động kiểm tra Node 22+, tự chạy npm install khi thiếu packages, tạo .env từ .env.example khi chưa có, giải phóng cổng 3000 khi bị chiếm và mở trình duyệt. Trên Windows, run.bat sở hữu giao diện màu ANSI hiện đại với thanh tiến trình trực quan 7 giai đoạn. Nhấn Ctrl+C trong console để dừng server.

Chạy thủ công:

npm install
npm run dev          # http://localhost:3000

Kiểm tra trạng thái runtime khi server đang mở:

powershell -ExecutionPolicy Bypass -File scripts/smoke-test.ps1

Cài đặt API key

Mở /setup. Hệ thống hỗ trợ hai nhóm provider:

  • Cloud: Gọi API qua mạng (cần key). Hỗ trợ Groq, NVIDIA và Token Harbor theo giao thức chuẩn OpenAI chat-completions, chia sẻ chung adapter trong src/lib/ai/openai-compatible.ts.
  • CLI: Điều khiển AI agent cục bộ trên máy, hoàn toàn không cần API key đám mây. Antigravity CLI (agy) được tích hợp sẵn — tự động đọc và học từ tài liệu tham khảo trong thư mục bạn chỉ định (xem chi tiết tại docs/ANTIGRAVITY.md).

Lấy key miễn phí tại console.groq.com/keys (Groq) hoặc build.nvidia.com (NVIDIA). Cả hai hãng đều cung cấp gói miễn phí không cần thẻ tín dụng, giúp chuyển đổi dự phòng mượt mà khi một bên chạm giới hạn quota. Server lưu key an toàn vào .env (các biến GROQ_API_KEY, NVIDIA_API_KEY, TOKENHARBOR_API_KEY) và giao diện luôn che mờ key.

Sinh bài giảng

Mở /studio và nhập chủ đề, môn học, khối lớp, số cảnh, thời lượng và ghi chú. Bạn có thể đính kèm tài liệu tham khảo (pdf, docx, xlsx, txt, md, csv, json, tối đa 40 MB mỗi tệp) hoặc dán trực tiếp văn bản.

Tiến trình tạo bài diễn ra qua hai bước và hiển thị trực tiếp (streaming):

  1. Lên dàn ý: Tạo tiêu đề, thể loại và thời lượng từng cảnh, xuất hiện chỉ sau vài giây.
  2. Soạn chi tiết: Từng cảnh được sinh độc lập và hiển thị ngay trên màn hình xem trước. Nếu một cảnh gặp sự cố mạng, cảnh đó sẽ giữ khung dàn ý tối giản — toàn bộ bài giảng không bao giờ bị gián đoạn.

Các thể loại cảnh bao gồm: gạch đầu dòng, công thức toán học KaTeX, bảng số liệu, đồ thị hàm số, các bước giải mẫu có đánh số (B1, B2…), câu hỏi trắc nghiệm, ảnh minh họa AI và mô phỏng 3D.

Mở /lesson. Thanh công cụ phía trên tích hợp ô tìm kiếm bài giảng trực tiếp từ thư viện máy tính (data/courses/), đi kèm huy hiệu phân loại trực quan.

Slide không phải video quay sẵn mà là một timeline thời gian thực do GSAP điều khiển: tua tới bất kỳ giây nào sẽ tái hiện chính xác trạng thái DOM, vị trí highlight phụ đề và khung hình chuyển động.

Các định dạng xuất bài giảng

  • 🌐 Xuất file HTML độc lập (/api/export/html): Đóng gói toàn bộ slide, mã nguồn GSAP, bộ dựng toán KaTeX và dữ liệu âm thanh base64 vào 1 file .html duy nhất. Nhấp đúp mở bằng mọi trình duyệt là xem và tương tác được ngay, không cần web server hay cơ sở dữ liệu.
  • 📝 Xuất phụ đề SRT (/api/export/srt): Tải file phụ đề chuẩn SRT với độ chính xác theo từng chữ, hỗ trợ cả chế độ câu liên tục và chế độ theo dòng thời gian.
  • 📦 Xuất kịch bản JSON (/api/export/json): Tải file cấu trúc dữ liệu bài học để lưu trữ hoặc tích hợp vào các hệ thống khác.

Thư viện bài giảng

Mở /library. Toàn bộ bài đã lưu được lưu dưới dạng file JSON dễ đọc trong thư mục data/courses/ trên ổ cứng. Mỗi thẻ bài cung cấp nút phát ngay, xem mã JSON và nút xóa. Cơ chế ghi file nguyên tử (.tmp → .json) đảm bảo an toàn dữ liệu, chống hỏng file khi mất điện đột ngột.

Giọng đọc & TTS Offline

Giọng đọc do server tổng hợp tự động, không cần thuê dịch vụ ngoài. Âm thanh được lưu đệm (cache) theo từng câu tại data/tts-cache/, giúp các lần phát lại diễn ra tức thì mà không tốn tài nguyên tính toán. Bạn có thể xóa thư mục này bất cứ lúc nào để giải phóng dung lượng ổ cứng. Hệ thống cũng hỗ trợ công cụ tổng hợp giọng đọc offline qua Piper (scripts/local-voice/piper_speak.py) cho môi trường biệt lập không có Internet.

Dọn dẹp & Reset hệ thống

uninstall.bat cung cấp menu chọn lọc thông minh với màu sắc ANSI trực quan:

  1. Dọn Cache & Build: Xóa .next/, data/tts-cache/ và file rác mà vẫn giữ lại bài giảng và thư viện packages.
  2. Gỡ bỏ Runtime: Xóa thư mục .runtime/ (Node portable, Python venv, model giọng đọc).
  3. Reset sạch sẽ: Xác nhận trước khi dọn node_modules/, .next/, .runtime/, cache âm thanh và bài giảng đã tạo. Toàn bộ mã nguồn dự án, file .env chứa API key và logo luôn được bảo vệ an toàn tuyệt đối.

Giới hạn hệ thống

  • Local-first: Không cần cơ sở dữ liệu. Bài giảng lưu thành file JSON trong data/courses/, âm thanh lưu trong data/tts-cache/. Muốn sao chép sang máy khác chỉ cần tải file JSON hoặc copy thư mục.
  • Quota API: Quá trình tạo bài cần API key còn hạn mức. Khi nhà cung cấp hết quota, hệ thống sẽ hiển thị thông báo lỗi rõ ràng kèm hướng dẫn khắc phục.
  • Xuất HTML độc lập: Dữ liệu và âm thanh được nhúng trực tiếp; ở lần mở đầu tiên trên trình duyệt mới, hệ thống kết nối Internet để nạp thư viện hiệu ứng CDN, sau đó hoạt động hoàn toàn offline.
  • Độ chuẩn xác khung hình: Khả năng tua theo khung hình dựa trên tỷ lệ 1/fps (mặc định 30 fps), có thể cấu hình cho từng bài giảng.
