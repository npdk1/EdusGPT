Everything You Need to Know

Clear answers about local execution, data privacy, and standalone exports.

Yes, 100%. EdusGPT is strictly local-first. All generated lessons are stored as atomic, human-readable JSON files directly in your computer's data/courses/ folder. There is no PostgreSQL, no SQLite, no user tracking, and no external database required.

No GPU is required! EdusGPT leverages cloud inference (such as DeepSeek-V3 via Token Harbor free tier, Groq, or NVIDIA) or local CPU-friendly models. Voice synthesis runs over Edge Neural TTS or lightweight CPU Piper models.

When you export to Standalone HTML, the server packs all slide layouts, GSAP timeline choreography, KaTeX math renderer, interactive quizzes, and neural narration audio into one single .html file. You can put it on a USB stick or email it, and it will play on any device without internet.

EdusGPT supports Token Harbor (DeepSeek-V3 free tier), Groq Cloud (Llama 3.3 70B & Qwen), NVIDIA NIM, Antigravity local CLI, and local Ollama endpoints. You can add or swap keys anytime from /setup in your browser.
