    05

    Chạy trên máy bạn

    Nhấp đúp run.bat (Win) hoặc ./run.sh (Mac/Linux). Xong mở /setup dán key Gemini / OpenRouter.

    • Bài lưu ở data/courses/ · giọng đọc ở data/tts-cache/.
    • Chạy tay: npm run dev — localhost:3000.

    Giới hạn nói trước

    Không database, không giấu quota

    Chưa làm được gì, đọc đây là đủ.

    • Không database. Bài là file trong data/courses/.
    • Hết quota thì báo rõ, không trả bài rỗng.
    • HTML xuất ra cần mạng ở lần mở đầu tiên.
    • 1 khung hình = 1/30s mặc định.

    Dọn sạch: clean_all.bat xóa bài + cache, giữ .env.local.

    Check: npm run verify.
